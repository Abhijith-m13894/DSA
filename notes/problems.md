# DSA Problems

This section contains solutions to actual DSA/interview problems.

## Purpose

The goal is to apply:

- Data structures
- Algorithms
- Problem-solving patterns
- Complexity analysis

to real problems.

## Problem Sources

Initially, the main source will be:

- NeetCode 150

Other sources can be added later:

- LeetCode
- Interview questions
- Company-specific problems
- Problems created for practice

## NeetCode 150

NeetCode 150 provides a structured collection of important interview problems.

Its categories will be preserved in the project so that we can track our progress.
