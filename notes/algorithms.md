# Algorithms

This section contains fundamental algorithms and algorithmic techniques.

## Purpose

The goal is to understand how algorithms work rather than simply memorizing solutions.

For each algorithm, we should understand:

- What problem it solves
- How it works
- Why it works
- Time complexity
- Space complexity
- Important variations
- When it should or should not be used

Implementations of fundamental algorithms and experiments that help understand them.

Individual interview problems should normally go under `problems`.

## Relationship with Problems

Algorithms provide techniques that can be applied to solve problems.

For example:

Binary Search → Search in Rotated Sorted Array  
DFS → Number of Islands  
BFS → Binary Tree Level Order Traversal  
Backtracking → Subsets / Permutations
