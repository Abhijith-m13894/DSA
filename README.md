# Data Structures & Algorithms

A structured Java repository for building strong foundations in **Data Structures, Algorithms, Problem-Solving Patterns, and Coding Problems**.

The goal is to develop a clear understanding of how data structures work, how algorithms are designed, and how common problem-solving patterns can be recognized and applied.

---

## Repository Intent

This repository is organized as a long-term reference system rather than a collection of unrelated coding solutions.

#### Objective

Build a strong and reusable foundation in Data Structures and Algorithms, with enough depth to:

- Approach unfamiliar coding problems systematically
- Recognize common problem-solving patterns
- Reason about complexity and trade-offs
- Write clean and maintainable Java implementations
- Use DSA concepts in real-world engineering

It separates:

- **Data Structures** - understanding how data is organized and accessed
- **Algorithms** - understanding systematic methods for solving problems
- **Patterns** - recognizing reusable problem-solving techniques
- **Problems** - applying those concepts to practical coding problems

---

## How the Repository Is Organized

### Data Structures

Contains implementations and experiments related to fundamental data structures.
Examples include arrays, linked lists, stacks, queues, hash maps, trees, heaps, tries, and graphs.

The focus is on understanding:

- How the structure works
- Core operations
- Time and space complexity
- Appropriate use cases
- Trade-offs and limitations

### Algorithms

Contains implementations of fundamental algorithms and techniques such as sorting, searching, recursion, backtracking, and traversal.
The focus is on understanding the **idea behind the algorithm**.

### Patterns

Contains reusable approaches that appear across many coding problems.

Examples include:

- Two Pointers
- Sliding Window
- Prefix Sum
- Binary Search
- DFS / BFS
- Monotonic Stack
- Backtracking
- Greedy
- Dynamic Programming
- Union-Find
- Topological Sort

A pattern represents a **way of thinking about a problem**.

### Problems

Contains solutions to coding problems from sources such as **NeetCode 150 and LeetCode**.
Problems are classified by their broader category, applicable pattern, data structure, and difficulty.
A problem has a single canonical implementation rather than being duplicated across multiple categories.

  #### Problem Documentation
  
  Problem solutions include concise documentation covering the important reasoning behind the solution, including:
  
  - Problem source and reference
  - Category
  - Problem-solving pattern
  - Data structure used
  - Difficulty
  - Time complexity
  - Space complexity
